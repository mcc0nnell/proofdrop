# ProofDrop

**Put money behind proof.**

ProofDrop is a deliberately tiny Base Mini App for USDC micro-bounties:

1. A creator escrows a small USDC reward.
2. A different wallet submits a public proof URL.
3. The proof URL is hashed and committed onchain.
4. The creator approves or rejects the proof.
5. Approval pays the claimant directly from escrow.

The v0 goal is not to build a generalized marketplace. It is to create a measurable, attributable Base app that can start with a tiny bankroll.

## Why this shape

- **No leverage.** Maximum loss is the bankroll actually deposited.
- **No admin key.** The escrow has no owner, fee switch, proxy, or upgrade path.
- **No self-claims.** A bounty creator cannot claim their own drop.
- **No hidden proof database.** Challenge and proof hashes are onchain; human-readable payloads are emitted as event URIs.
- **ERC-8021 ready.** Set `NEXT_PUBLIC_BUILDER_CODE` and wagmi appends Base Builder Code attribution to every transaction.
- **Mini App ready.** `/.well-known/farcaster.json` is generated by the Next app.

## Stack

- Next.js 16 / React 19
- wagmi + viem
- `@farcaster/miniapp-sdk`
- `@farcaster/miniapp-wagmi-connector`
- `ox/erc8021` for Builder Code attribution
- Solidity 0.8.34
- Hardhat 3 + viem tests

## Contract state machine

```text
OPEN --claim--> CLAIMED --approve--> PAID
  |                 |
cancel            reject
  |                 |
CANCELLED <------ OPEN
```

A claimant can also withdraw a pending claim, reopening the drop.

## Run locally

```bash
cp .env.example .env.local
npm install
npm run dev
```

The app defaults to Base Sepolia and will stay in dry-run mode until contract addresses are configured.

## Validate

```bash
npm run lint
npm run test:contracts
npm run build
```

Contract tests cover:

- escrow + approved payout
- creator self-claim rejection
- rejected proof reopening the bounty
- creator cancellation + refund

## Testnet deployment

Use `MockUSDC.sol` plus `ProofDrop.sol` on Base Sepolia. After deployment, set:

```env
NEXT_PUBLIC_CHAIN=base-sepolia
NEXT_PUBLIC_PROOFDROP_ADDRESS=0x...
NEXT_PUBLIC_USDC_ADDRESS=0x...
NEXT_PUBLIC_DEPLOYMENT_BLOCK=...
```

Do not switch `NEXT_PUBLIC_CHAIN` to `base` until the testnet flow has been exercised end to end.

## Mainnet deployment

ProofDrop accepts the USDC contract address in its constructor. Base mainnet USDC is configured in the frontend when `NEXT_PUBLIC_CHAIN=base`.

Before moving real funds:

- verify the deployed source on a Base block explorer;
- test create → claim → reject → re-claim → approve/pay;
- test cancel/refund;
- claim a Base Builder Code and verify the ERC-8021 suffix in a transaction;
- complete the Mini App domain association;
- perform an independent contract review.

This repository is an experimental prototype, not an audited escrow product.

## Real-money rule

The experiment starts with a hard cap. No leverage, no borrowing, and no automatic bankroll replenishment. Testnet costs nothing; mainnet only starts after the deployment and wallet flow are verified.
